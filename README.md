# Android App - Enterprise Foundation
Source: vascs-enterprises

Ye VASCS ka main engine hai.

Tech: Kotlin + Jetpack Compose + Material 3 + Room DB V7 + Hilt

Isme ye hai:
- Product Master (SKU, Barcode, HSN, GST, Stock)
- 9 DAOs: ProductDao, OrderMasterDao, OrderItemDao, DealerWalletDao, UserDao, AdminConfigDao, AiDrapeResultDao, FinishedGoodsDao, ActivityLogDao
- Super Admin Dashboard - 15 tabs
- AI Drape Studio (FAB)

Status: Phase 1 - Super Admin Control Center building
